# Writing Style

Rules for written output produced by any contributor or agent in this repository:
prose, code comments, commit messages, PR descriptions, chat replies, and file
content.

## No em-dashes, ever

Never use an em-dash (`-`, U+2014) anywhere. This includes the HTML entity forms
(`&mdash;`, `&#8212;`, `&#x2014;`).

Use standard punctuation instead:

- A colon for definitions or appositive elaborations.
- Parentheses for parenthetical clauses.
- A comma for short asides.
- A period or semicolon to split sentences.
- An ASCII hyphen (`-`) for compound modifiers and ranges.

En-dashes (`-`, U+2013) are acceptable for numeric ranges only.

If existing content contains em-dashes, treat them as a defect and convert them on
sight.
